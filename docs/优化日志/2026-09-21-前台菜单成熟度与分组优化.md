# 2026-09-21 前台菜单成熟度与分组优化

## 目标

将左侧菜单从“功能清单平铺”调整为“常用工作流 + 成熟度分层 + 规划能力折叠”，避免已交付能力、部分能力和规划能力混在一起。

## 变更

1. 常用入口固定为：总览、任务中心、协作总线、后台服务。
2. 生命体区、工作台区、治理区、观测区改为可折叠分组。
3. 每个菜单项显示成熟度：
   - 可用：核心数据或控制链路已接通；
   - 部分：可操作，但仍有 Mock、降级或未闭合能力；
   - 规划：后端注册表或业务能力尚未接入。
4. Phase 6/7/8 未接入能力收进分组内“规划与演示”，开发环境仍可预览，生产环境可继续按成熟度隐藏。
5. 侧栏 Agent 在线面板从 `mock.ts` 切换为 `/api/wp/agents/online`，每 30 秒刷新；不可用时显示原因，不展示固定 Mock Agent。
6. 模块详情页增加“部分可用 / 规划预览”提示，与菜单状态保持一致。
