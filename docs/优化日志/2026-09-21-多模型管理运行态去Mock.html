2026-09-21 多模型管理运行态去 Mock¶

目标¶

把“多模型管理”中仍依赖 managedModels / modelRoutes 的演示运行态，改为真实配置、探测、用量和 Prometheus 指标聚合。

实施¶

  1. 新增 GET /api/wp/models/runtime： - nlp-service llm_model_config：模型配置、角色、启用状态、探测结果； - nlp-service llm_token_usage：调用、失败、Token、平均延迟、流量份额； - Prometheus lifeform_llm_*：角色 QPS、失败率、P95 推理延迟。
  2. 原“模型池运行态”改为“模型接入运行态”。
  3. 原“模型路由策略”改为真实角色路由配置：角色优先、routing_weight 排序、故障后层级降级。
  4. 成本、质量、供应商配额、队列指标没有可信数据源，统一返回 unsupported_fields，页面显示“未接入”。
  5. 删除页面中 managedModels、modelRoutes、modelTokenTrend 的 Mock 引用。

验证¶

  • wp-bff：119/119 通过；
  • 前端：24/24 通过；
  • TypeScript / 生产构建：通过；
  • 契约：implemented 50 路径 / 54 方法，planned 20，0 FAIL；
  • 真实接口验证：当前租户无模型配置时返回 items=[] 与真实路由空态，不伪造模型。
  • 真实响应归档：docs/test-reports/model/2026-09-21/runtime-overview.json。

边界¶
