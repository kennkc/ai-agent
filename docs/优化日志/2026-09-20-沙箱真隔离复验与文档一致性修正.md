## 5. 发现的残留项（已登记，非阻塞）

`DockerSandboxBackend.available()` 是**刻意非阻塞**的设计：

```java
// 缓存过期 → 投递后台探测 → 立即返回旧值
if (过期 && refreshing.compareAndSet(false, true)) { 启动后台线程 doProbe(); }
return lastProbeResult;   // ← 可能是 15s 前的旧值
```

后果：在 15s 缓存刷新的瞬间，**状态端点报告 docker 可用，但实际执行会降级到受限进程**
（我在复验中真实遇到：同一分钟内 `/api/tool/sandbox` 返回 docker，而执行返回 process-restricted）。

建议（对 `sandbox_required=true` 的工具）：探针刷新期间**有界等待**（如 1-2s）或**直接拒绝执行**，
而不是静默降级 —— 安全语义上，「以为在沙箱里」比「明确失败」危险。
