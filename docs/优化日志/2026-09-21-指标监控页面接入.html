2026-09-21 指标监控页面接入 Prometheus / Micrometer¶

目标¶

在观测区新增“指标监控”页面，用固定 PromQL 模板展示系统级 Prometheus / Micrometer 指标，不把 Prometheus 查询面直接暴露给浏览器。

实现¶

  1. 新增 GET /api/wp/metrics/overview： - Target 健康与最近抓取错误； - HTTP QPS、错误率、平均/最大延迟； - JVM 堆、线程、GC； - HikariCP 活跃/最大/等待连接； - LLM、Collab、Tool 业务指标； - Prometheus 活动告警。
  2. job 与 window 都使用白名单；不接受任意 PromQL。
  3. 查询结果缓存 10 秒，避免前端短轮询放大 Prometheus 压力。
  4. 新增观测区菜单“指标监控”和 MetricsView.vue。
  5. HTTP P95 / GC P95 未暴露 histogram bucket 时明确标记“未启用”，不伪造分位值。
  6. 指标不带 tenant 标签，因此明确标记为 system 级指标，不伪装多租户隔离。

  • wp-bff：120/120 通过；
  • 前端：27/27 通过；
  • TypeScript / 生产构建：通过；
  • Playwright Mock：2/2；Live API：1/1；
  • 契约：implemented 51 路径 / 55 方法，planned 20，0 FAIL；
  • 真实 Prometheus：8/8 targets up，指标接口返回 HTTP、JVM、Hikari 与告警数据；
  • 真实响应：docs/test-reports/metrics/2026-09-21/overview.json。
