# R-MC01-05 真实协作域接线与前端测试补强（2026-09-20）

> **范围**：MC-01 协作总线独立切片收口 · **性质**：真实数据接线 + 前端测试补强 + 契约/报告同步
> **结论**：R-MC01-05 已闭合；工作平台不再把固定 `DOM-2048` 当作真实协作域，上游不可用时仍保留可见降级。

---

## 1. 本轮解决的问题

| 问题 | 修复前风险 | 本轮处置 |
|---|---|---|
| 工作平台协作视图仍使用固定演示域 `DOM-2048` | 即使 collab-bus 已有真实域，页面仍展示演示数据 | provider 先调用 `/collab/domains`，优先 `VITE_COLLAB_DOMAIN_ID`，否则使用真实列表首项 |
| wp-bff 未代理 collab-bus 协作域 | 前端跨服务直连，协议映射散落前端 | 新增 `/api/wp/collab/domains` 与 `/api/wp/collab/{domain_id}`，由 BFF 统一映射成员/进度/拓扑 |
| 上游不可达可能被渲染成“没有协作域” | 故障与服务空态混淆 | 返回 200 + `available=false` + `reason`，前端登记 `collaboration_domains` 降级并保留 Mock |
| 前端缺少 provider 与总览页测试 | 真实域接线缺少回归保护 | 新增 provider 真实域选择测试、OverviewView 真实摘要/降级快照测试 |
| OpenRouter free router 输出不稳定 | 可能把非降级误报成质量通过 | 固定上游模型复测并判定 `pass`；`openrouter/free` 仅保留 smoke 用途 |

## 2. 关键实现

### 2.1 BFF 协作域代理

- `GET /api/wp/collab/domains`：透传 `X-Tenant-Id`，返回 `available/total/items/reason/checked_at`。
- `GET /api/wp/collab/{domain_id}`：把 collab-bus 的 `members/progress/stale_count` 映射为工作平台协作视图的 `agents/messages/dag/...`；`stale/blocked -> blocked`、`idle -> waiting`，不把阻塞或空闲成员误报为执行中。
- collab-bus 不可达时不伪造成功：返回 200 + `available=false`，由前端显式降级。
- BFF 是唯一字段映射边界；前端 provider 不再复制 collab-bus 原始结构解析逻辑。

### 2.2 前端自动选域

1. 先读取 `/collab/domains`；
2. 若 `VITE_COLLAB_DOMAIN_ID` 存在且列表命中，则使用该域；
3. 否则使用真实列表首项；
4. 域列表为空或请求失败时登记 `collaboration_domains` 降级；
5. 禁止继续把 `DOM-2048` 作为真实数据路径。

### 2.3 测试补强

- provider：断言先请求 `/collab/domains`，再请求真实域详情，不再请求固定演示域。
- OverviewView：覆盖今日摘要、模型监控、OPS 观测摘要真实数据渲染，以及接口异常时“最近一次可用快照 + 明确告警”。
- wp-bff：新增协作域列表代理、真实聚合映射、上游不可达降级 3 条回归。
- 契约：`/collab/domains` 与 `/collab/{domain_id}` 均标记 `implemented`。
