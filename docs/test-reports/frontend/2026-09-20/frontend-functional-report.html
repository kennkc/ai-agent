3. 测试发现并修复的问题¶

组件测试暴露出 MiddlewareView 在以下响应下会渲染崩溃：

{
  "enabled": false,
  "items": []
}

原因是 health summary 为空时直接读取 overview.summary.down。本轮已改为：

overview.value?.summary?.down ?? 0

并增加“中间件观测服务未启用”回归用例。
